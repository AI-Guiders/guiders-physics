# AIGuiders.Physics.MediaCodec

4D video and studio audio streaming codec (`CuboctMediaCodec`) with SIMD `Vector256<byte>`, reversible Sub-Green color decorrelation, 2-point acoustic Verlet parabola prediction, and Two-Point Keyframe-Drop interpolation (`Stride N = 2, 4, 8, 12`) inside the Heisenberg `[-40, +40]` deadband.
